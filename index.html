      About Flash Cards

      Build your own study decks and practice one question at a time. Your decks and cards are saved, so you can pick up where you left off.

      Create a deck

      Choose New Deck, select a color, and paste your deck as JSON. Give it a name between 2 and 80 characters and include a question and answer for every card. Use an empty cards array to start with a blank deck.

      {
  "name": "Web Basics",
  "cards": [
    {
      "question": "What does HTML stand for?",
      "answer": "HyperText Markup Language"
    }
  ]
}

      Practice and make changes

      Open a deck and choose Practice. Use the arrows to move between cards and the flip button to reveal an answer.

      Choose New Card to add a question, flip to enter its answer, and select the check mark to save. Use the pencil to edit a card or the trash icon to delete it. Deletions ask for confirmation.
